# Phased-Antenna-Array
4-element beamforming phased array targeting 5.8 GHz, with beamsteering range of ± 45°.

Antenna Report.docx contains all the antenna parameters, design choices, performance measurements, and sources used in the construction of this project. phased_array_antenna.cst contains all the data necessary to reproduce the array in CST Studio Suite.

power combiner.sch represents the schematic for the Wilkinson power combiner, and can be imported into QUCS Studio. The corresponding .dpl file represents the simulation output.
